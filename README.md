# Blinkit Sales Analytics Dashboard

An interactive Power BI dashboard developed to analyze Blinkit's grocery sales performance. The report transforms transactional data into clear, actionable insights on sales, products, outlet characteristics, and customer ratings.

## Project Overview

This project provides a consolidated view of Blinkit's retail performance, helping stakeholders explore the factors that influence sales across product categories and outlet types. Interactive filters allow users to examine performance from multiple business perspectives.

## Business Objectives

- Monitor overall sales performance and core business KPIs.
- Analyze sales by item type and item fat content.
- Compare outlet performance by size, location type, and establishment year.
- Track average sales, average customer rating, item count, and outlet count.
- Support data-driven decisions for product assortment and outlet strategy.

## Dashboard Features

- **KPI cards:** Total Sales, Average Sales, Average Rating, Total Items, and Total Outlets.
- **Product analysis:** Sales performance by item type and fat-content category.
- **Outlet analysis:** Sales comparison by outlet size, outlet location type, and outlet establishment year.
- **Interactive exploration:** Slicers and dynamic metric selection for focused analysis.
- **Visual storytelling:** Bar charts, donut charts, and trend visualizations designed for quick interpretation.

- **Power BI Desktop** - Data modeling, DAX measures, interactive report design, and visualization.

## Data Fields Analyzed

The dashboard analyzes fields including sales, customer ratings, item identifier, item type, item fat content, outlet identifier, outlet size, outlet location type, and outlet establishment year.

## How to Use

1. Download or clone this repository.
2. Open `blinkitB1.pbix` in **Power BI Desktop**.
3. Use the available filters and visuals to explore sales and outlet performance.

## Key Business Questions Answered

- Which product categories contribute most to sales?
- How does item fat content affect sales performance?
- Which outlet sizes and locations generate stronger sales?
- How does sales performance vary across outlet establishment years?
- What are the current average sales and customer-rating levels?
